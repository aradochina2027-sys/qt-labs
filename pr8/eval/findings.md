# Висновки ПР8

Під час виконання практичної роботи було реалізовано помічника клієнта магазину, який використовує виклики інструментів для роботи із замовленнями, товарами, доставкою, складом і поверненнями.

## Результати перевірки

Для перевірки було підготовлено 20 питань:
- 15 основних;
- 5 власних.

Під час першого прогону успішно пройдено 5 питань.

### Успішні питання

- q01 — модель правильно обрала інструмент `get_order` і показала інформацію про замовлення 10458.
- q02 — модель правильно обрала `list_orders` і показала список замовлень клієнта.
- q03 — номер замовлення `№ 10 458` був правильно оброблений як `10458`, після чого використано `get_order`.
- q04 — для неіснуючого замовлення 99999 інструмент `get_order` повернув коректну відповідь, що замовлення не знайдено.
- q06 — модель використала `list_orders` і показала замовлення клієнта, визначеного кодом.

У цих випадках модель правильно обирала інструменти, а відповіді формувалися на основі результатів сервісу магазину.

## Помилки під час прогону

Після кількох успішних запитів API мовної моделі почав повертати помилку:

`ліміт запитів до моделі тимчасово вичерпано`

Для повторних спроб у `run_eval.py` було реалізовано очікування та повтор запиту.

Також оброблялася помилка HTTP 503.

Навіть після повторних спроб із паузами сервіс моделі продовжував повертати обмеження за кількістю запитів.

У результаті:
- успішно — 5 питань;
- з помилками через ліміт API — 15 питань.

## Обробка помилок

Програма не завершується аварійно при помилці API.

При виникненні rate limit або HTTP 503:
- помилка перехоплюється;
- виконується повторна спроба;
- результат зберігається у `eval/results.json`;
- вже успішно виконані питання не запускаються повторно.

Таким чином, прогін можна продовжити пізніше без втрати попередніх результатів.

## Безпека

Ідентифікатор клієнта не передається моделлю як аргумент інструмента, а визначається кодом.

Адміністративні операції, наприклад зміна ціни, статусу замовлення або бонусів, не надаються моделі як доступні інструменти.

Моделі повертаються тільки потрібні для відповіді дані без службової інформації.

## Підсумок

Робота з інструментами реалізована та перевірена на частині тестового набору.

Успішні тести підтвердили правильний вибір інструментів і роботу сервісу магазину.

Повний прогін набору був обмежений зовнішнім лімітом API мовної моделі. Помилка була коректно оброблена програмою, а результати перевірки збережені у `eval/results.json`.
