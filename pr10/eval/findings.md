# Практична робота №10
## Надійний AI-сервіс і AI UX

### Мета роботи
Розробити надійний AI-сервіс для створення чернеток відповідей клієнтам із підтримкою потокової генерації, повторних спроб, таймаутів, скасування та обмеження запитів.

### Результати виконання

Розроблено застосунок на FastAPI, який підтримує справжній OpenAI-сумісний API Google Gemini та тестовий провайдер mock.

### Аналіз стійкості

1. **Таймаути.** Використано обмеження часу однієї спроби, бездіяльності потоку та загального часу генерації. Для реальних перевірок установлені значення 30, 15 і 90 секунд відповідно. Результати п'яти звернень показали, що їх достатньо для перевірених умов.

2. **Повторні спроби.** Тимчасові збої, зокрема unavailable та timeout, допускають повторення. Помилки auth і bad_request не повторюються, оскільки повторення без зміни умов не усуває їхню причину.

3. **Обрив потоку.** Якщо текст уже почав надходити, автоматичний повтор не виконується, щоб уникнути дублювання або несподіваної заміни відповіді.

4. **Скасування.** Фонову генерацію можна скасувати. Після скасування чернетка отримує статус cancelled. Скасування завершеної чернетки повертає HTTP 409.

5. **Обмеження запитів.** За ліміту 10 запитів за хвилину перші десять запитів було прийнято, наступні відхилено з HTTP 429. Сервер повернув заголовок Retry-After.

6. **Одночасність.** За обмеження двох одночасних звернень до провайдера з п'яти створених чернеток дві завершилися успішно, а три — помилкою до початку спроби.

7. **Запасний варіант і mock.** Підставний провайдер використовується для відтворюваних перевірок без API-ключа. Запасний варіант призначений для створення позначеної резервної відповіді, коли основний провайдер недоступний.

### Виявлені проблеми

Спочатку в програмі були незавершені функції, які спричиняли HTTP 500. Їх було реалізовано.

Модель gemini-3.8-flash не змогла завершити тестову генерацію в межах установлених таймаутів. Після переходу на gemini-3.5-flash-lite потокова генерація успішно запрацювала.

Найбільш помітною проблемою стали таймаути попередньої моделі. Заміна моделі дозволила отримати відповіді для п'яти звернень.

### Висновок

У ході практичної роботи реалізовано та перевірено AI-сервіс для створення чернеток відповідей клієнтам. Застосунок підтримує фонову генерацію, streaming, таймаути, повторні спроби, скасування, обмеження запитів та контрольовані помилки.

Виконано перевірки стійкості за допомогою mock-провайдера. Справжня модель gemini-3.5-flash-lite успішно опрацювала п'ять звернень із середнім часом першого фрагмента 1,233 секунди та повної відповіді 1,541 секунди.

Отримані результати підтверджують працездатність основних механізмів застосунку в перевірених сценаріях.
